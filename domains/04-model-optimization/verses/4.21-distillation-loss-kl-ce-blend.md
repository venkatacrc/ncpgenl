# 4.21 — Distillation loss (KL + CE blend)

**Objective:** 4.3

$$\mathcal{L}=\alpha\,T^2\,\text{KL}(p_T^{teacher}\;\|\;p_T^{student})+(1-\alpha)\,\text{CE}(y,\,p^{student})$$

- KL term matches softened distributions (temperature `T`); the `T²` factor rescales
  gradient magnitude softened by `T`.
- CE term keeps the student honest to ground-truth labels.
- `α` balances the two.

```python
import torch.nn.functional as F
def distill_loss(s_logits, t_logits, y, T=2.0, alpha=0.5):
    kl = F.kl_div(F.log_softmax(s_logits/T, -1), F.softmax(t_logits/T, -1),
                  reduction="batchmean") * (T*T)
    ce = F.cross_entropy(s_logits, y)
    return alpha*kl + (1-alpha)*ce
```
