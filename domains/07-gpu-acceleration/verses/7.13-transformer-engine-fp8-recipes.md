# 7.13 — Transformer Engine FP8 recipes  `[H100-ONLY]`

**Objective:** 7.2

**Transformer Engine (TE)** provides FP8 training/inference on **Hopper+**: FP8 GEMMs
(E4M3 fwd, E5M2 grads, 4.06) with **per-tensor scaling factors** maintained via a
**delayed-scaling** recipe (track a rolling window of amax to set scales). Wrap layers
in `te.Linear`/`te.TransformerLayer` under an `fp8_autocast`. Big speedup + memory cut on
H100 with near-BF16 accuracy.

> **GB200/Blackwell upgrade:** the **2nd-gen Transformer Engine** (`sm_100`) adds **FP4
> (NVFP4) training/inference** with micro-block scaling (4.08) — finer-grained than
> Hopper's per-tensor delayed scaling — for even higher throughput and smaller memory.
> **A100 fallback:** use BF16 AMP (7.10/7.12) — same mixed-precision concept, no FP8/FP4
> units on Ampere.

```python
import transformer_engine.pytorch as te
from transformer_engine.common.recipe import DelayedScaling
with te.fp8_autocast(enabled=True, fp8_recipe=DelayedScaling()):
    out = te_model(x)
```
