# 7.06 — Sequence parallelism

**Objective:** 7.1

Sequence Parallelism (SP) splits along the **sequence/token dimension**, sharding the
activations of the normally-replicated ops (LayerNorm, dropout) that Tensor Parallelism
leaves un-split. Combined with TP (Megatron-SP), it cuts activation memory for long
sequences without extra compute. For very long context, context/ring-attention variants
extend this idea across GPUs.
