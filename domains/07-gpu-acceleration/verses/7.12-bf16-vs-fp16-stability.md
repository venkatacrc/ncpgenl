# 7.12 — BF16 vs FP16 training stability

**Objective:** 7.2

Both are 16-bit Tensor Core formats. **BF16** (1-8-7) has FP32's exponent range → no
loss scaling, robust to overflow, the default for LLM pretraining on Ampere+.
**FP16** (1-5-10) has more mantissa precision but a narrow range → needs loss scaling
and can still overflow on large activations/gradients. Rule: prefer BF16 for training
stability; use FP16 only where required.
