# 7.28 — Profiling-driven optimization loop

**Objective:** 7.4

Disciplined loop (NVIDIA APOD: Assess, Parallelize, Optimize, Deploy):
1. **Assess** — profile with Nsight Systems to find the biggest bottleneck (never
   optimize by guessing).
2. Classify it: GPU-idle (data/comm), memory-bound, compute-bound, launch-bound.
3. Apply the matching fix (7.20–7.27).
4. **Re-profile** to confirm and find the next bottleneck; iterate.

Measure one change at a time; optimize the dominant cost first (Amdahl).

**Chain →** An optimized, trained model must now be served in production — **Domain 8:
Model Deployment.**
