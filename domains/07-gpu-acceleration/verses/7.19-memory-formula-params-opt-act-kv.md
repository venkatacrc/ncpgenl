# 7.19 — Training memory formula

**Objective:** 7.2

Approximate GPU memory for training (mixed precision, Adam):
- **Weights**: `P × 2` bytes (BF16).
- **Gradients**: `P × 2` bytes.
- **Optimizer (Adam)**: FP32 master + m + v ≈ `P × 12` bytes.
- **Activations**: ∝ batch × seq × hidden × layers (dominant at long context;
  checkpointing cuts it).

Rule of thumb: full Adam training ≈ **~16–20 bytes/param** before activations, so a 7B
model needs ~112–140 GB → why FSDP/parallelism/PEFT. Inference adds the **KV cache**
(4.26) instead of optimizer states.
