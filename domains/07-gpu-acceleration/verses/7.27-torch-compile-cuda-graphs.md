# 7.27 — torch.compile / CUDA graphs (launch overhead)

**Objective:** 7.4

Many tiny kernels make **launch overhead** (CPU dispatching each kernel) the
bottleneck — common in decode with small batches. **CUDA Graphs** capture a sequence of
launches once and replay them as a single unit, removing per-launch CPU cost.
**`torch.compile`** fuses ops and can use CUDA graphs automatically. Big wins for
latency-bound, launch-heavy workloads (small-batch inference).
