# 2.12 — Prompt learning: soft vs hard prompts

**Objective:** 2.1

**Hard prompts** are discrete natural-language tokens (everything above). **Soft
prompts** are continuous, *trainable* embedding vectors prepended to the input; the
model weights stay frozen while only these vectors are learned via backprop —
parameter-efficient adaptation for small datasets/specialized domains. This is the
bridge to **P-tuning / prefix tuning** in Domain 5 (5.15).

```text
[p1][p2]...[pk]  <actual input tokens>
# p1..pk are learned float vectors, not tokens from the vocabulary
```

**Chain →** Soft prompts help small data — but what if we just spend more inference
compute to reason harder? (2.13)
