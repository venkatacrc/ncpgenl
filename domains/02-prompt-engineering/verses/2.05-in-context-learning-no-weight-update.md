# 2.05 — In-context learning (no weight update)

**Objective:** 2.2

In-context learning (ICL) = the model conditions on exemplars in the prompt and adapts
its output distribution **without any gradient step**. Weights are frozen; "learning"
is transient, living only in the forward pass's activations/KV cache. Implication:
ICL cannot add durable knowledge or survive across sessions — that is what fine-tuning
(Domain 5) is for. Distinguish sharply from **prompt learning / P-tuning** (2.12),
which *does* train continuous prompt vectors.
