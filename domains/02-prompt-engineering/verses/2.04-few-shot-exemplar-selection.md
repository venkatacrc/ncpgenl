# 2.04 — Few-shot prompting & exemplar selection

**Objective:** 2.2

Few-shot = k examples (typically 2–8). Accuracy rises with informative, **diverse,
class-balanced** exemplars; degrades with redundant or skewed ones. **Recency/order
matters** — models over-weight later examples. Retrieval-based selection (pick
exemplars similar to the query) beats fixed sets on heterogeneous inputs. Bounded by
context length and cost.

```text
# 3-shot, class-balanced, then the query
pos -> "Loved it."
neg -> "Broke in a week."
neu -> "It's fine, nothing special."
query -> "The battery drains too fast."
```
