# 5.13 — Multi-LoRA serving

**Objective:** 5.2

Because adapters are tiny and the base is shared, one deployment can serve **many LoRA
adapters** simultaneously, routing each request to its adapter (per-task/per-tenant).
The base weights load once; adapters swap cheaply (or batch heterogeneously with
specialized kernels). NVIDIA supports **multi-LoRA** in TensorRT-LLM / NIM. Trade-off:
un-merged adapters add a small per-layer compute overhead vs a merged single-task model.
