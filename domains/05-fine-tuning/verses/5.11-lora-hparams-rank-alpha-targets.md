# 5.11 — LoRA hyperparameters

**Objective:** 5.2

- **rank `r`**: capacity of the update (4–64 typical); too low underfits, too high wastes
  params and risks overfit.
- **alpha `α`**: scaling; effective scale `α/r`. Common heuristic `α = 2r`.
- **target modules**: which projections get adapters — attention `q_proj,k_proj,v_proj,
  o_proj` (and often MLP). More targets = more capacity.
- **dropout**: regularizes the adapter.

```python
from peft import LoraConfig
cfg = LoraConfig(r=16, lora_alpha=32, lora_dropout=0.05,
                 target_modules=["q_proj","k_proj","v_proj","o_proj"])
```
