# 5.14 — Adapters (bottleneck modules)

**Objective:** 5.2

Adapter tuning inserts small **bottleneck** modules (down-project → nonlinearity →
up-project, with a residual) **between** frozen transformer sublayers; only adapters
train. Unlike LoRA (which reparameterizes existing weight matrices and can be merged),
adapters add **new layers**, so they **cannot be merged away** and add inference latency.
Historically first PEFT method; LoRA largely superseded it for LLMs.

**Chain →** LoRA/adapters modify weights or add layers — is there a PEFT that only
touches the input? (5.15)
