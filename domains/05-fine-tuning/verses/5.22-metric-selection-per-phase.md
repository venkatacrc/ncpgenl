# 5.22 — Metric selection per phase

**Objective:** 5.3

Match the metric to the phase and task:
- **Training**: loss (CLM/contrastive) for optimization.
- **Validation**: task metric for model selection/early stopping — perplexity (LM),
  accuracy/F1 (classification), BLEU/ROUGE (generation), retrieval recall@k
  (embeddings).
- **Test**: held-out final report; add human/LLM-judge for open-ended quality (Domain
  6).

Never select the model on the test set (leakage, 3.11). Pick a **single** primary
metric to avoid ambiguous model selection.

**Chain →** Metrics assess quality; a specific failure to fix in fine-tuning is
hallucination — how? (5.23)
