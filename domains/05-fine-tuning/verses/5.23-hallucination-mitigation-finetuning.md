# 5.23 — Hallucination mitigation via fine-tuning

**Objective:** 5.4

Fine-tuning levers against hallucination: train on high-quality **grounded** data
(answers tied to sources), include **"I don't know"** examples so refusal is learned,
prefer **RAG** for knowledge-heavy tasks over parametric memorization (2.21, 2.23), and
align with preference methods (DPO) that penalize fabrication. Over-training on narrow
data can *increase* confident hallucination — balance with diverse data.
