# 5.25 — Assessing fine-tuning impact (xref D6)

**Objective:** 5.4

Measure before/after on a **held-out** set with the primary task metric **and** a
regression check on general capability (to catch forgetting, 5.26). Use paired
comparisons, fixed decoding/seeds, and enough samples for significance. Track both the
target improvement and side-effects (safety, other tasks). Formal evaluation frameworks
(Ragas, NeMo Evaluator, LLM-as-judge) are Domain 6.

**Chain →** A key risk when assessing impact is losing prior abilities — what is it and
how to prevent it? (5.26)
