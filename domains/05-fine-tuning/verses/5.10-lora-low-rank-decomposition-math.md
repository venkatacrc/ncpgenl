# 5.10 — LoRA: low-rank decomposition math

**Objective:** 5.2

LoRA freezes pretrained `W₀ ∈ ℝ^{d×k}` and learns a **low-rank update**:

$$W = W_0 + \Delta W = W_0 + \frac{\alpha}{r} BA,\qquad B\in\mathbb{R}^{d\times r},\; A\in\mathbb{R}^{r\times k},\; r\ll\min(d,k)$$

Only `A, B` train (parameters ∝ `r(d+k)` instead of `d·k`). `A` init random Gaussian,
`B` init zero (so ΔW starts at 0). At inference `BA` can be **merged** into `W₀` → zero
added latency.

```python
delta = (alpha / r) * (B @ A)   # add to W0
```
