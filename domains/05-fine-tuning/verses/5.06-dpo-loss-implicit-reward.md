# 5.06 — DPO: direct preference optimization

**Objective:** 5.1

DPO skips the explicit reward model and RL loop: it reparameterizes the RLHF objective
so the optimal policy defines an **implicit reward**, giving a simple classification
loss on preference pairs against a frozen reference:

$$\mathcal{L}_{DPO}=-\log\sigma\!\Big(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}-\beta\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\Big)$$

(`y_w`=chosen, `y_l`=rejected). Only policy + reference in memory; stable, no reward
model, no sampling loop. The `β` controls deviation from the reference.
