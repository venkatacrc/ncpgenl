# 5.20 — Early stopping & patience

**Objective:** 5.3

Monitor a **validation** metric each eval interval; stop when it fails to improve for
`patience` consecutive checks, and restore the **best** checkpoint. Prevents overfitting
and wasted compute. Levers: `patience`, `min_delta` (minimum improvement to count),
which metric to watch. Pairs with a warmup/cosine schedule (4.32) and HP search
(4.34, kill weak trials early).

```python
if val_metric < best - min_delta:
    best, wait = val_metric, 0; save("best.pt")
else:
    wait += 1
    if wait >= patience: stop()
```
