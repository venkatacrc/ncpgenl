# 9.11 — Automated tuning pipelines

**Objective:** 9.4

Wrap retraining in a reproducible pipeline: data validation → (re)train/fine-tune →
automated eval (Domain 6) → gated promotion → canary → monitor. Orchestrate with MLOps
tools; on NVIDIA, **NeMo** recipes + **Base Command** / cluster schedulers run the
training jobs, and the eval/serving stack gates promotion. Hyperparameter search (4.34)
can run inside the pipeline. Everything versioned for reproducibility.
