# 9.06 — Drift: data vs concept

**Objective:** 9.2

- **Data (covariate) drift**: the input distribution changes (new topics, languages,
  slang) while the target mapping holds.
- **Concept drift**: the input→output relationship itself changes (what counts as
  "spam" evolves).

Detect via distribution distances (PSI, KL, embedding-space monitoring) on inputs and
outputs. Drift silently degrades quality with no error thrown → triggers retraining
(9.10). This is the top cause of "the model got worse over time."

**Chain →** Drift signals degradation vs a baseline — how do we benchmark against prior
versions? (9.07)
