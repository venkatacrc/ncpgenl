# 1.09 — Extract embeddings from an encoder

**Objectives:** 1.3, 1.6

Two standard poolings over the encoder's last hidden state: the `[CLS]` token vector,
or **masked mean pooling** over token vectors. Mean pooling usually wins unless the
model was fine-tuned to make `[CLS]` a sentence representation (Sentence-Transformers
exist precisely for this reason).

```python
from transformers import AutoTokenizer, AutoModel
import torch
tok = AutoTokenizer.from_pretrained("bert-base-uncased")
enc = AutoModel.from_pretrained("bert-base-uncased").eval().cuda()
b = tok(["a cat sat", "a dog ran"], padding=True, return_tensors="pt").to("cuda")
with torch.no_grad():
    h = enc(**b).last_hidden_state              # [B, T, d]
m = b.attention_mask.unsqueeze(-1)              # [B, T, 1]
mean_emb = (h * m).sum(1) / m.sum(1)            # masked mean pooling -> [B, d]
```
