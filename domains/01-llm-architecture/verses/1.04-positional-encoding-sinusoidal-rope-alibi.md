# 1.04 — Positional encoding

**Objective:** 1.2

Order is injected explicitly.

- **Sinusoidal** (fixed, additive): `PE(pos,2i)=sin(pos/10000^{2i/d})`,
  `PE(pos,2i+1)=cos(...)`. Extrapolates modestly.
- **Learned absolute**: trainable position table; **cannot extrapolate** past trained
  length.
- **RoPE** (rotary): rotates `Q,K` by a position-dependent angle so the dot product
  depends only on the **relative** offset; strong extrapolation; default in modern
  decoders (Llama, Qwen).
- **ALiBi**: adds a **linear distance penalty** to attention logits; cheapest, strong
  extrapolation.

```python
import torch
def sinusoidal(T, d):
    pos = torch.arange(T)[:, None]
    i   = torch.arange(0, d, 2)[None, :]
    ang = pos / (10000 ** (i / d))
    pe = torch.zeros(T, d); pe[:, 0::2] = ang.sin(); pe[:, 1::2] = ang.cos()
    return pe
```
