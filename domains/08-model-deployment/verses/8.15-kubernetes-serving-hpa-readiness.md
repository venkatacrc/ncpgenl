# 8.15 — Kubernetes serving (HPA, readiness)

**Objective:** 8.3

Deploy the serving container as a K8s **Deployment** with GPU resource requests,
**readiness/liveness probes** (Triton's `/v2/health/ready`) so traffic only routes to
ready pods, and a **Service**/ingress. Scale with the **Horizontal Pod Autoscaler**
(HPA) on GPU/custom metrics (queue depth, latency). NVIDIA provides Helm charts and the
GPU Operator. Use rolling updates for zero-downtime (ties to 9.13).
