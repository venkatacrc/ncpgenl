# 8.01 — Cost profiles: encoder vs decoder vs enc-dec

**Objective:** 8.1

- **Encoder-only**: one forward pass, no autoregression, no KV cache — cheapest,
  lowest latency (classification/embeddings).
- **Decoder-only**: autoregressive — prefill (parallel) then per-token decode (serial) +
  KV cache; latency scales with output length.
- **Encoder-decoder**: full encoder pass + autoregressive decoder + cross-attention —
  most expensive per request, but the encoder runs once.

Match model type to the latency/throughput/cost budget (ties to 1.05–1.07).
