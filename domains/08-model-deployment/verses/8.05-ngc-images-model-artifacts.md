# 8.05 — NGC images & model artifacts

**Objective:** 8.2

**NGC (NVIDIA GPU Cloud)** is the catalog of GPU-optimized container images (PyTorch,
Triton/Dynamo-Triton, TensorRT-LLM, NeMo), pretrained models, and Helm charts. Pull with
`docker pull nvcr.io/nvidia/...`. Model artifacts (engines, checkpoints, `config.pbtxt`)
live in a **model repository** the server mounts. Pin image tags for reproducibility;
engines are GPU-arch-specific (4.23).

**Chain →** With container and artifacts, which server serves LLMs and how is it
structured? (8.06)
