# 8.13 — NIM microservices overview

**Objective:** 8.2

**NVIDIA NIM (NVIDIA Inference Microservices)** package an optimized model (often
TensorRT-LLM engine) + Triton + an **OpenAI-compatible REST API** into a single
container with sensible defaults, auto-selecting the best engine for the detected GPU.
NIM trades some low-level control for turnkey, production-grade deployment and standard
APIs. Part of NVIDIA AI Enterprise.
