# 8.04 — Containerized inference pipeline

**Objective:** 8.2

Package the model + runtime + dependencies into a container for reproducible, portable
deployment. A serving pipeline = preprocess (tokenize) → model (engine) → postprocess
(detokenize), often as a Triton **ensemble** (8.12). Containers pin CUDA/driver-
compatible runtimes and enable both `docker run` and Kubernetes deployment. NVIDIA ships
prebuilt serving containers on **NGC**.
