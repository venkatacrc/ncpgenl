# 8.08 — Continuous (in-flight) batching

**Objective:** 8.2

**Continuous / in-flight batching** (TensorRT-LLM) operates at the **iteration
(token-step)** level: as soon as one sequence in the batch finishes, its slot is freed
and a queued request joins immediately — no waiting for the whole batch. This keeps the
GPU saturated despite highly variable output lengths, dramatically improving throughput
and latency for LLM serving. Paired with **paged KV cache** for memory efficiency.
