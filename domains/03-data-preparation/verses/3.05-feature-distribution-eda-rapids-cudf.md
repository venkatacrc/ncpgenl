**Objective:** 3.1

Profile distributions before training: token-length histograms, vocabulary coverage,
language/topic mix, outliers, and correlations. On large corpora this is IO/compute
heavy — **RAPIDS cuDF** gives a pandas-like API on GPU for order-of-magnitude speedups
(NVIDIA's recommended tool). Length distributions directly drive `max_seq_len` and
padding/packing decisions (3.12).

```python
import cudf                       # GPU DataFrame, pandas-like
df = cudf.read_parquet("corpus.parquet")
print(df["n_tokens"].describe())  # p50/p95/p99 to pick max_seq_len
```
