# 3.01 — Data cleaning: dedup, normalization

**Objective:** 3.1

Cleaning removes noise that models otherwise memorize: exact/near-duplicate documents,
inconsistent Unicode (NFC/NFKC normalization), stray whitespace/control chars, boiler-
plate, and encoding errors (mojibake). Deduplication both improves generalization and
prevents train/test leakage. NVIDIA accelerates this at scale with **NeMo Curator**
(3.06) on GPU (RAPIDS).

```python
import unicodedata, re
def clean(t):
    t = unicodedata.normalize("NFKC", t)
    t = re.sub(r"\s+", " ", t).strip()
    return t
```
