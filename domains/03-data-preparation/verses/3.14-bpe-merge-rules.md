# 3.14 — BPE (Byte-Pair Encoding) merge rules

**Objective:** 3.3

BPE starts from characters (or bytes, "byte-level BPE" — GPT-2/Llama) and **greedily
merges the most frequent adjacent pair** repeatedly, recording an ordered merge list
until the target vocab size is reached. Encoding re-applies merges in order.
Byte-level BPE guarantees no OOV for any Unicode input. Used by GPT, RoBERTa, Llama.

```text
init:  l o w </w>, l o w e r </w>, ...
merge most frequent pair (e.g. "l o" -> "lo"), repeat
final vocab = base chars + learned merges
```
