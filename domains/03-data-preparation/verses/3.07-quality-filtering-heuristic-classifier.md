# 3.07 — Quality filtering (heuristic + classifier)

**Objective:** 3.1

Two layers: **heuristic filters** (document length, symbol-to-word ratio, mean word
length, fraction of alphabetic chars, repeated-line/n-gram ratios, stop-word presence)
cheaply drop junk; **classifier-based filters** (a small model scoring "high-quality
like reference corpus") catch subtler low-quality text. NeMo Curator ships both.
Over-filtering hurts diversity; tune thresholds against a validation sample.

**Chain →** Filtered text can still contain massive duplication — how is that removed at
scale? (3.08)
